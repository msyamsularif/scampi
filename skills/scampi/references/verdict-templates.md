# Scampi verdict templates (Bahasa Indonesia)

Ready-made examples to copy the structure from. **Always** take the content
from the tool payload — these templates only show the shape, they are not a
substitute for the data.

## 1. Likely scam — link phishing bank

```
🚨 Kemungkinan besar penipuan

Alasan:
• Mengaku BCA, tetapi domain yang dipakai bukan domain resmi — link "bca-klik-promo.xyz" bukan milik BCA
• Domain baru berumur 5 hari
• Meminta OTP/PIN/data rahasia
• Cocok dengan pola penipuan yang dikenal: "Akun bank diblokir + link verifikasi"

Yang sebaiknya kamu lakukan:
1. Jangan klik tautan atau memasukkan data apa pun.
2. Jangan transfer uang ke rekening/nomor ini.
3. Kalau sudah terlanjur klik atau transfer, segera hubungi call center resmi bank/instansi terkait.
4. Laporkan melalui kanal resmi (mis. OJK 157 atau aduan Komdigi).

Catatan: Ini penilaian otomatis dari sinyal yang tersedia — bukan keputusan
hukum. "Tidak ditemukan tanda bahaya" bukan jaminan bahwa pesan itu aman.
```

## 2. Caution — account has been reported (not yet verified)

```
⚠️ Perlu hati-hati

Alasan:
• Nomor rekening pernah dilaporkan 1 pengguna (belum terverifikasi penuh)

Yang sebaiknya kamu lakukan:
1. Jangan terburu-buru — tunda dulu sampai terverifikasi.
2. Cek lewat kanal resmi: aplikasi/situs resmi atau call center resmi yang kamu tahu sendiri.
3. Jangan pernah membagikan OTP, PIN, atau data kartu ke siapa pun.

Catatan: 1 laporan saja belum tentu benar — pastikan dulu sebelum menyimpulkan.
Ini penilaian otomatis, bukan keputusan hukum.
```

## 3. No red flags found — legitimate promo

```
✅ Tidak ditemukan tanda bahaya

Alasan: tidak ada sinyal yang dikenali dari data yang dikirim. Domain
"klikbca.com" adalah domain resmi BCA, dan tidak ada pola penipuan yang cocok.

Yang sebaiknya kamu lakukan:
1. Tetap waspada — belum ada sinyal yang dikenali, tapi ini bukan jaminan aman.
2. Jangan pernah membagikan OTP/PIN meskipun yang mengirim mengaku dari bank.

Catatan: Ini penilaian otomatis dari sinyal yang tersedia — bukan keputusan
hukum.
```

## 4. With inactive sources (degradation)

State them verbatim, one line per source:

```
Catatan: Google Safe Browsing tidak aktif (API key belum diisi), jadi link
tidak dicek ke daftar blokir Google. URLhaus dan umur domain tetap diperiksa.
```

## 5. Screenshot

Start by naming the source:

```
Saya baca dari gambar yang kamu kirim. Screenshot berisi pesan yang mengaku
dari kurir "JNE" dan satu link.

🚨 Kemungkinan besar penipuan
...
```
